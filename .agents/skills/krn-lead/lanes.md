# Lane brief: common rules for background agents
- Repository /mnt/storage/coding/krn/active/krn, remote krn-works/krn. Create your worktree: `bin/krn lane start <slug> [--task <id> --actor <name>]` (fetches origin main, branches `<slug>`, adds `.krn/worktrees/<slug>`, claims; prints path and branch); work only there. Never edit the main checkout, other worktrees, ~/.claude or ~/.agents (operator: nothing global). Temp files under /mnt/storage/tmp, never /tmp. Never `pkill -f`; stop processes by PID.
- Operator grant (verbatim): "Na wszystko masz zgodę as long as we will achieve a fucking breakthrough"; "wypierdol bramki po prostu koduj".
- Delivery: `npm run fast` before every commit, and for wide changes `npm test > /mnt/storage/tmp/<slug>-test.log 2>&1; echo exit=$?` (never hide exit codes behind a pipe). Commit titles are `type(scope): <outcome> (<task-id>)`; final trailer paragraph exactly:
  Ticket: <task-id>
  Co-Authored-By: <your model> <noreply@anthropic.com>
  Task records: create new tasks with `bin/krn task create` and close yours with `bin/krn task close <id> --as done --note ...` run INSIDE your worktree (cd there first) so the record ships with your PR. Never edit `docs/program/roadmap.md`.
- Hooks: never bypass git hooks (`--no-verify`, `-c core.hooksPath=...`, `HUSKY=0`); if a hook blocks or misfires, fix the hook in your PR or report it in your final reply.
- Ship: from the repository root run `bin/krn pr ship --worktree <your worktree> --title "type(scope): <outcome> (<task-id>)" --body-file <file>` (body: sections of `.github/pull_request_template.md`, then the Claude Code line; `--force` after a rebase). It pushes, auto-merges, removes the worktree and branch, then prints a `verdict:` line. Tracker edits ride in the PR. Red `Check` (exit 74): read `bin/krn ci logs --run <id>` into a file, grep it; a real test failure is your defect, fix, commit and rerun ship; an infra flake: `gh run rerun <id> --failed` then `bin/krn ci wait --repo krn-works/krn --pr <n> --head <sha> --base <sha>`. Conflict (76): rebase onto origin/main and `--force`.
- Append one line per finding/PR to .krn/runs/lead/<campaign>/ledger.md: `- <lane>: <finding> -> PR #n merged|task t-xxx|dropped (<reason>)`.
- Final reply ≤10 lines (it is the report; Claude Code refuses subagent report files): PRs with merge state, tasks created, measured before/after numbers.
- Lane types: untrusted content (web, papers, clones under .krn/sources) runs as `krn-research` (read-only; lead saves its report under .krn/runs); recon and logs as `krn-reader`. Probes, tests and commands run in a general-purpose lane that reads no untrusted page. Lanes of 100+ turns were $167 of $216 subagent spend: slice a general-purpose lane to about 60 turns; at turn 80 push and report the rest.
- Budget: `krn lane start` refuses (64) under 5 GB free (repo or /mnt/storage/tmp; `KRN_LANE_MIN_FREE_GB`) or at 8 live worktrees (`KRN_LANE_MAX_LIVE`). Brief states a size budget: fix ~30 turns, slice ~60, ceiling 80; ~150 tool calls.
