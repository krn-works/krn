# Lane brief: common rules for background agents
- Repository /mnt/storage/coding/krn/active/krn, remote krn-works/krn. Create your own worktree: `git -C /mnt/storage/coding/krn/active/krn fetch -q origin main && git -C /mnt/storage/coding/krn/active/krn worktree add -b <branch> .krn/worktrees/<branch-slug> origin/main`; work only there. Never edit the main checkout, other worktrees, ~/.claude or ~/.agents (operator: nothing global). Temp files under /mnt/storage/tmp, never /tmp. Never `pkill -f`; stop processes by PID.
- Operator grant (verbatim): "Na wszystko masz zgodę as long as we will achieve a fucking breakthrough"; "wypierdol bramki po prostu koduj". No briefs/review ceremony.
- Delivery: `npm run fast` before every commit (format, tsc, related + rule tests), and for wide changes `npm test > /mnt/storage/tmp/<slug>-test.log 2>&1; echo exit=$?` (never hide exit codes behind a pipe). Commit titles end with `(<task-id>)`; final trailer paragraph exactly:
  Ticket: <task-id>
  Co-Authored-By: <your model> <noreply@anthropic.com>
  Task records: create new tasks with `bin/krn task create` and close yours with `bin/krn task close <id> --as done --note ...` run INSIDE your worktree (cd there first) so the record ships with your PR.
- Hooks: never bypass git hooks (`--no-verify`, `-c core.hooksPath=...`, `HUSKY=0`); if a hook blocks or misfires, fix the hook in your PR or report it in your final reply.
- Ship: `git push -u origin <branch>` (after a rebase `--force-with-lease`), `gh pr create --head <branch> --base main --title "<plain outcome> (<task-id>)" --body-file <file>` (sections of `.github/pull_request_template.md`, then the Claude Code line), `gh pr merge <n> --auto --squash`. Tracker edits ride in this PR. Then wait for the PR (poll `gh pr view <n> --json state,statusCheckRollup` every 60s, max 40 min; never `gh pr checks --watch`). Red `Check`: read `gh run view <id> --log-failed` into a file, grep it; a real test failure is your defect — fix and push; an infra flake (runner/network) — `gh run rerun <id> --failed`. If main moved and conflicts, rebase onto origin/main.
- When done remove your worktree (`git worktree remove`) and local branch.
- Append one line per finding/PR to .krn/runs/lead/<campaign>/ledger.md: `- <lane>: <finding> -> PR #n merged|task t-xxx|dropped (<reason>)`.
- Final reply ≤10 lines: PRs with merge state, tasks created, measured before/after numbers.
- Lane types: a lane that reads untrusted content (web pages, papers, third-party clones under .krn/sources) runs as the `krn-research` agent (`.claude/agents/krn-research.md`: no Bash, Edit or sub-agents; writes one report under .krn/runs). A lane that must run probes, tests or commands is a general-purpose lane and reads no untrusted page.
