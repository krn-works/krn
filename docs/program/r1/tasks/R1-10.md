## Purpose / Big Picture

`foreman/state.ts` and `foreman/git.ts` act as a hidden shared kernel for relay, trace, verdict and flow; there is an
import cycle `foreman → verdict → foreman`; the `git` helper exists in seven copies and `killAndVerifyScope` in two (with
different `systemctl` flags: `--kill-who` vs `--kill-whom`). After this change, shared I/O lives in two named modules,
every module's allowed imports are data, and a test fails on any new forbidden edge.
