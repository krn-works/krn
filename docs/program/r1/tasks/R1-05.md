# R1-05: Record the base ref at start; remove host-specific hard-coding

Seed ExecPlan per `docs/program/PLANS.md`. Owner: worker. Wave 1. Priority 1. Finding F-06 (P2, blocks R1-12 on repos
whose default branch is not `main`).

## Purpose / Big Picture

J1 should run on any target repository. Today every capsule refresh computes `git merge-base HEAD main`, so a repository
whose default branch is `master` (or anything else) fails at the first `repoFacts` call. After this change, `krn start`
records the base ref once, every later step uses it, and the toolchain lookups no longer assume mise or one user's home.

## Context and Orientation

- `src/relay/index.ts:100` `git(job, ['merge-base', 'HEAD', 'main'])` [CODE].
- `src/cli/index.ts:35-82` `start()` creates `.krn/worktrees/<id>` on branch `krn/<id>` from `HEAD` and calls
  `recordRepo(job, root)` [CODE].
- `src/foreman/state.ts:17-99` `recordSchema` `{repoRoot, gitDir, gitWorkTree}` written once to
  `.krn/runs/foreman/<id>/repo.json` with `wx` [CODE].
- `src/verdict/sandbox.ts:105-121` `pnpmBinary()` requires `mise where pnpm@x.y.z` [CODE].
- `scripts/gate-local.mjs:116-117` hard-codes `/home/krn/.local/share/mise/installs/gh/latest/.../gh` [CODE].

## Plan of Work

1. `recordSchema` gains `baseRef: z.string().min(1).optional()` (optional only for records written before this change).
2. `krn start` accepts `--base <ref>`; default resolution order: `--base`; `git symbolic-ref --quiet --short
   refs/remotes/origin/HEAD` (strip `origin/`); the branch checked out in the main repository at start time. Store the
   resolved ref name in `repo.json`. Refuse with a clear error if the ref does not resolve to a commit.
3. `repoFacts()` uses `repoRecord(job).baseRef ?? 'main'` (the fallback keeps old jobs working; record that decision).
4. `pnpmBinary()`: if `mise` is not on `PATH`, fall back to `pnpm` on `PATH` and require `pnpm --version` to equal the
   `packageManager` version; otherwise refuse as today.
5. `scripts/gate-local.mjs`: `const ghPath = process.env.KRN_GH_BIN ?? 'gh'`, resolved through `PATH`.

## Falsifier (red first)

`test/relay/base-ref.test.ts`, test `repo facts use the recorded base of a master-default repository`: init a temp repo
with `--initial-branch=master`, ignore `.krn/`, commit, run `node src/cli/main.ts start --job j1 --issue X` in it, commit
once in the job worktree, then call `repoFacts(job)` **inside a wrapper that returns `{error}` instead of throwing**, and
assert `facts.base === <master sha>`. At base the wrapper returns an error → assertion failure (not an exception), as
required. Add a unit test for the default-resolution order.
