# R1-06: Make the primary metric v2 computable

Seed ExecPlan per `docs/program/PLANS.md`. Owner: worker. Wave 2. Priority 1. Depends on R1-05 (`src/cli/index.ts`).
Operator decision D1 (charter 2026-10-10 §1). Finding F-02 (P1).

## Purpose / Big Picture

The E1 kill criterion compared operator minutes with a baseline of 0, so it could never fire. D1 replaces the primary
metric with accepted outcomes without escaped defects, reported with lead interventions, reconstruction prompts and tokens
per outcome. After this change those counters are recorded by the tool, validated by schema, and the live record file
for L2 (R1-12) has a defined shape.

## Context and Orientation

- `src/evals/journey-baseline.ts` defines `journeyBaselineSchema` (`n`, `tasks[]` with `operator_minutes`,
  `reconstruction_prompts`, `first_useful_action`, `lost_stages`, `tokens`, `judge_rounds`, `outcome`); unknown values are
  `{value: null, reason}` [CODE]. `evals/journeys/j1-baseline.json` has n=3, all `operator_minutes: 0`,
  `reconstruction_prompts` unknown [CODE].
- `src/trace/index.ts` appends JSONL events with an idempotency key; `operatorStart/operatorStop` exist [CODE].
- `src/cli/index.ts` `stop()` builds a `Job` from `--job --issue --worktree [--repo-root]` [CODE].

## Plan of Work

1. Trace: `leadIntervention(job, kind: 'intervention' | 'reconstruction_prompt', note: string)` appends
   `lead_intervention` events (`note` single line ≤200 chars, no newlines; key `lead-intervention:<uuid>`).
2. CLI: `krn note --job --issue --worktree [--repo-root] --kind intervention|reconstruction --text "<≤200>"`.
   Add `note` to the migrated command list in `src/cli/main.ts:20`.
3. Schema: add `lead_interventions` and `escaped_defects` (metric values) to the task row; **required** for rows labelled
   `valid`. Export a new `journeyLiveSchema` for `evals/journeys/j1-first-live.json`:
   `{schema: 2, records: [{issue, repo, commit, job, interrupted_at_event, resumed_session_id, lead_interventions,
   reconstruction_prompts, escaped_defects, tokens:{input,output}, outcome, limitations[], evidence[]}]}`.
4. Data: update `evals/journeys/j1-baseline.json` rows with `lead_interventions` and `escaped_defects`. Use real values
   only if the host's B0 records (`.krn/runs/**/results.md`, ignored files — read them per KRN-09) state them; otherwise
   `{value: null, reason: "<why>"}`. Never invent numbers.
5. Docs: replace the kill criterion paragraph in `docs/program/blueprint.md` §12 with the D1 text from the charter and a
   link; add one line to the "Changelog" at the bottom.
