## Purpose / Big Picture

krn's own verdict registry omits `test` because the suite is not green inside the verdict sandbox (74 pass, 52 fail).
Behaviour is therefore never checked by the verdict path. After this change, `krn.checks.json` declares `test` and
`judge()` on a krn commit passes with the full suite.

## Context and Orientation

- `evals/journeys/e1-results.json` states the cause [OURS-EVIDENCE]: "The isolation helper fails instead of skipping when
  CI is not true; the sandbox runner then exits 125 after detecting detached check processes."
- `test/helpers/isolation.ts` → `scripts/isolation-gate.mjs` `decideIsolation()`: skip only when `CI === 'true'`,
  otherwise fail [CODE].
- `src/verdict/sandbox.ts:330-355`: the in-sandbox monitor (PID 1 via `bwrap --as-pid-1`) kills and flags any process
  whose parent is PID 1 after the check exits, returning 125 [CODE]. `scripts/test-suite.mjs:22-40` spawns the test runner
  `detached`, and several tests spawn their own process groups [CODE].
- Inside the sandbox there is no systemd user bus (`--clearenv`, no `XDG_RUNTIME_DIR`), so systemd-dependent tests
  cannot run there.

## Plan of Work

1. Give the sandbox an explicit, honest mode: `execute()` sets `KRN_VERDICT_SANDBOX=1` in the sandbox environment
   (`src/verdict/sandbox.ts` `--setenv`).
2. `scripts/isolation-gate.mjs` `decideIsolation()`: treat `KRN_VERDICT_SANDBOX=1` like CI (skip with the
   `SKIP(isolation): …` line), so skips are counted, never silent. Do not change the host or `gate:local` behaviour.
3. Find which processes survive the check (run the suite under the sandbox, list PID-1 children before the monitor
   kills them) and fix the cause in the test or helper that leaks them, not in the monitor. The monitor's strictness
   stays.
4. Add `{"id":"test","argv":["npm","test"],"timeoutMs":600000}` to `krn.checks.json`.
5. Update `evals/journeys/e1-results.json`: remove `registry_limitation` and add a dated note with the evidence
   (`judge` output for the merge commit). Do not touch other fields.
