## Purpose / Big Picture

Checks run candidate code with `bwrap --ro-bind / /`, so they can read the operator's home (for example `~/.codex`,
`~/.ssh`); the 2 KB output tail is stored under `.krn`. After this change checks see only system directories, the
toolchain, the pnpm store copy, and their own worktree.

## Context and Orientation

`src/verdict/sandbox.ts:357-363` builds the bwrap argv; the toolchain lives under mise in the operator's home
(`pnpmBinary`, `process.execPath`) [CODE].

## Plan of Work

Replace `--ro-bind / /` with read-only binds of `/usr`, `/bin`, `/lib`, `/lib64` (when present), `/etc` (or a minimal
subset), the directory of `process.execPath`, the pnpm directory, plus the existing writable bind of the worktree copy and
`--tmpfs` home. Add `--ro-bind-try` for paths that may not exist.
