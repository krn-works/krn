# LON-130 standards packet

**Standards / pitfalls.** Memory read is offline and read-only: no hidden fetch, store write, or status mirror. Bind provenance, scope, source/store/request revision, freshness and successor resolution. Disputed, expired, unavailable, changed-source or wrong-scope records are not current automatic context. Distinguish absence, bundle miss, unavailable evidence and budget omission; relevance proves neither sufficiency, correctness nor authority. Missing required complements/contradictions block only their dependent consequential transition. Refuse unsafe/symlink/secret-shaped paths without echoing values. Expected failures return typed results; parse at file/process boundaries. Add one runtime falsifier, show behavioral RED first, preserve existing observers.
