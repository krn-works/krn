# LON-131 standards packet

**Standards / pitfalls.** A proposal is a candidate, never an accepted record. Preserve original source identity/revision/evidence and consumer; reject missing provenance, cross-scope edits, dangling/cyclic successors and unresolved contradiction. Bind candidate to schema, store revision, request revision and covering Paperclip issue. Emit changes only in the authorized workspace; never silently write accepted records. Corrections retain predecessor/source history. Verification rechecks original evidence/freshness and must not stamp or mutate records. Promotion belongs to integrator through source/schema checks and both independent exact-head judges; unrelated code-task acceptance is not memory acceptance. Expected invalidity is a result, not an exception. Test runtime boundary red-first and retain assertion strength.
